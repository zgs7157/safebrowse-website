防护不是一道开关，而是一整套流程

从页面加载前到文件落盘后，每一环都在本地完成，不依赖云端、不留浏览痕迹。

沙箱内核

Chromium 多进程隔离：每个标签页独立、低权限，网页代码无法直接接触你的系统。

威胁拦截

恶意域名黑名单 + 启发式规则：品牌仿冒、裸 IP、punycode、@ 伪装、短链接，导航前实时判定。

下载检疫

文件先入隔离区静态扫描再放行；可执行与脚本文件默认直接阻止。

应急熔断

独立看门狗进程每秒监控浏览器心跳，异常时封锁隔离区、清缓存、终止进程树并记录事件。

不留痕

独立浏览器配置目录，Cookie 不持久化：看完即走，本机不残留浏览数据。

图形化设置

黑名单、白名单、拦截阈值、防护开关，在设置面板里点几下就能改，保存立即生效。

常见问题

会把正常网站拦下来吗？

不会。默认黑名单只内置了两个官方恶意测试域名；启发式规则只在多特征同时命中、评分达到危险阈值时才整页拦截。常用站点已在白名单，也可以在设置面板把站点加入白名单。

远程桌面看会黑屏吗？

不会。SafeBrowse 会自动检测会话类型：远程桌面或远程协助时自动用软件渲染，本地使用时开启硬件加速，兼顾流畅度与兼容性。

还需要装杀毒软件吗？

建议配合 Windows Defender 或其它杀毒软件使用。SafeBrowse 的防护是「上网防护 + 应急处置」，不是对已感染系统的查杀工具，两者定位不同。

是开源的吗？

是的。完整源码在 GitHub 仓库，欢迎查看、改进和分发。
